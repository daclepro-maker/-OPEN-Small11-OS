# 💻 OPEN-Small11-OS | The Ultralight Windows Experience
> **"Performance, revived. Perfect for low-storage devices."**

![Small11 Banner](<img width="1666" height="912" alt="Tiny11" src="https://github.com/user-attachments/assets/85d3c769-17fb-4c42-b96b-e3be61e858ab" />) *(Note: Ensure your image is named 'image.png' and is in the same folder, or update this link)*

**OPEN-Small11-OS** is a custom, heavily stripped-down version of Windows 11 designed specifically for devices where storage space and RAM are at a premium. This project focuses on removing the bloat to deliver a fast, responsive, and minimalist operating system.

---

### 🚀 Key Features
* **🚀 Blazing Fast:** Boot times and app launches are drastically improved due to reduced background processes.
* **💾 Extremely Small Footprint:** Takes up significantly less disk space compared to a standard Windows 11 installation.
* **🛠️ Minimalist:** Stripped of unnecessary apps, telemetry, and pre-installed clutter (no Cortana, no bloatware).
* **💻 Optimized for Chromebooks:** The ideal solution for Chromebooks and legacy laptops with limited eMMC storage (e.g., 32GB or 64GB devices).
* **🔋 Better Battery Life:** Lower CPU and RAM usage translate to improved battery efficiency on portable devices.

---

### 🔧 What's Removed (The "Small" Part)
This OS focuses on essential functionality only. We’ve removed:
* Most pre-installed UWP apps (Bloatware)
* Microsoft Edge (Optional re-install possible)
* Windows Defender (Optional re-install possible for security)
* Telemetry and Tracking services
* Unnecessary System Drivers and Services
